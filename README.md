# TL-Search
Terminal User Interface (TUI) Local Search is a TUI application 
that stores URL, titles, and body from website

Installation:
1. Download source code
2. Run `./gradlew.bat run --console=plain` for Windows, `/gradlew.bat run --console=plain` for *unix systems in terminal

# Usage:
- input 1 to start scraping
- input 2 to start searching
## scraping
- write URL (with protocol!!!)
## searching
- input search query
